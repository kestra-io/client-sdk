# WorkerSelectorMatch

How selector tags are matched against a Worker Queue's tag set. ALL: queue tags must be a superset of the selector tags. ANY: queue tags must intersect the selector tags. Defaults to ALL when null.

## Enum

* `ALL` (value: `'ALL'`)

* `ANY` (value: `'ANY'`)
